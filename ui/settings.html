上游地址和 key

从所选的 magpie 自定义供应商读取 Responses 地址和 key，不复制密钥，key 轮换后自动跟随。只支持自定义供应商。

key 不在这里填（面板能读到的选项都应视为公开）：用 magpie plugin login codex-relay 或「供应商」页登录时填写。

选项里有明文 apiKey。建议改为复用供应商或登录时填写，再用命令行把它从选项里删除。

模型

模型列表来自上游 /models，在「供应商 → Codex Relay」里选择要开放哪些，这里不用填。模型名保持上游 id，例如 codex-relay/vendor/model-a。

以下三个字段留空时插件不声明对应能力，由供应商页面决定（高级 → 上下文窗口、最大输出；模型 → 名称与推理档位）。这里填的值对所有模型生效，请按上游实际能力填写。

    保存后几秒内自动生效。identity、setHeaders 等高级选项不在这里显示，保存时原样保留，用 magpie plugin options 修改。
